# Mon Portfolio

Un portfolio personnel simple et élégant, hébergé sur GitHub Pages.

## Structure

```
portfolio-github/
├── index.html    # Page principale
├── style.css    # Styles CSS
├── script.js    # Interactions JavaScript
└── README.md    # Ce fichier
```

## Personnalisation

1. **Modifier le nom** : Ouvrez `index.html` et remplacez "Votre Nom" par votre prénom
2. **Ajouter vos projets** : Dupliquez les blocs `.project-card` dans la section Projets
3. **Changer les couleurs** : Modifiez les variables CSS dans `style.css`
4. **Ajouter vos liens** : Remplacez les `#` par vos liens GitHub, LinkedIn, etc.

## Déploiement sur GitHub Pages

1. Créez un nouveau dépôt sur GitHub (nom: `votre-pseudo.github.io`)
2. Poussez ce code vers le dépôt principal (branche `main`)
3. Allez dans **Settings** → **Pages**
4. Sélectionnez la branche `main` et cliquez sur Save
5. Votre site sera disponible à `https://votre-pseudo.github.io`
